# Портфолио Ильи

Статический двуязычный сайт-портфолио (русский и английский) для проектной работы: сайты с заявками, внутренние инструменты, боты и автоматизация. Главные кейсы — действующий сайт с CRM для автосервиса и прототип Homeasy. В `dist/` находятся готовые HTML/CSS/JS страницы, локальные изображения и автономные демонстрационные интерфейсы с вымышленными данными. Сайт не требует сборки и внешних API. Язык переключается вручную в шапке; адрес каждой языковой версии отдельный.

## Публикация — Cloudflare Pages с Git integration

Публичный адрес: `https://portfolio.rustycat.cc/`. Репозиторий подключён через **Workers & Pages → Pages → Connect to Git**.

- GitHub repository: `elijahsol13/portfolio`.
- Production branch: `main`.
- Framework preset: `None`.
- Build command: оставить пустой.
- Build output directory: `dist`.
- Root directory: корень репозитория.

При обновлении `main` Cloudflare Pages публикует содержимое `dist/`. После выкладки нужно проверить обе языковые версии, страницы кейсов и демоверсии по публичным адресам.

Этот репозиторий содержит исключительно статические публичные файлы. Локальная конфигурация `.openai/` игнорируется Git и не включается в сайт.
