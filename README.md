# Портфолио Ильи

Статический двуязычный сайт-портфолио (русский и английский), показывающий разработку, автоматизацию и инфраструктурный опыт. Главные кейсы — действующий сайт и система заказов автосервиса, а также прототип Homeasy; отдельный блок раскрывает опыт работы с Linux/VPS, запуском, мониторингом и поддержкой сервисов. В `dist/` находятся готовые HTML/CSS/JS страницы, локальные изображения и автономные демонстрационные интерфейсы с вымышленными данными. Сайт не требует сборки и внешних API. Язык переключается вручную в шапке; адрес каждой языковой версии отдельный.

## Публикация в Cloudflare

Публичные адреса: `https://portfolio.rustycat.cc/` и `https://portfolio.elijah-rustycat.workers.dev/`. Сайт опубликован через существующий Cloudflare Worker `portfolio`. 20 октября 2026 года обновили позиционирование на «Веб-приложения и автоматизация», навигацию по компетенциям и подачу кейсов на русском и английском языках. Публикация проверяется по обоим адресам.

Исходники: `elijahsol13/portfolio`, ветка `main`. Публикуемый каталог: `dist/`; сборка не требуется. Обновление существующего Worker из корня репозитория: `npx wrangler deploy --name portfolio --assets dist --compatibility-date 2026-10-19`. Для публикации требуется авторизация Wrangler в аккаунте владельца. В Cloudflare у Worker есть Builds, привязанные к `main`, но после коммитов 20 октября автоматический деплой не появился; конфигурацию Builds стоит проверить перед следующим обновлением.

В актуальной версии обновлены позиционирование, русские и английские тексты, PDF CV и JSON-сценарий для n8n. Архитектурная карта и симулятор автоматизации убраны с главной, чтобы первый экран, кейсы и подтверждённые результаты оставались в центре внимания. Демонстрационные экраны системы заказов сохранены внутри кейса как дополнительное подтверждение выполненной работы.

После выкладки проверить обе языковые версии, страницы кейсов и демоверсии по обоим публичным адресам.

Этот репозиторий содержит исключительно статические публичные файлы. Локальная конфигурация `.openai/` игнорируется Git и не включается в сайт.
